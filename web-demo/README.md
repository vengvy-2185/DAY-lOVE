# Web Demo (no backend required)

Open `index.html` directly in any browser. It's a self-contained,
front-end-only preview of the Day Life UI (login, chat, admin dashboard)
running on mocked in-memory data — nothing persists on reload and no
server is required.

This is for quickly previewing the look & feel. For the real app with a
database, real auth, and file storage, use the `server/` + `client/`
folders instead (see the root README.md and DEPLOYMENT.md).
